# Advanced-OS-Project

# Counting Prime Numbers

# Instructions:
 - To run with default M, N and C values: go run main.go <pathname>
 - To run with custom M, N and C values: go run main.go <pathname> <M> <N> <C>
 - To build the project: go build main.go
 - To run the executable: ./main <pathname> <M> <N> <C>


Note: <pathname> is mandatory. M, N and C are optional.
If not provided, default values will be used (M=1, N=65536, C=1024).
